## 二、因子详细规范

### 因子 1：反转 return_42d ⭐ 最强单因子
- **定义**：`-return_42d = -(close/close_42d前 - 1)`，横截面 z-score 排序
- **方向**：买近 2 个月跌得多的（均值回归），卖涨得多的
- **适配环境**：
  - 周期：短周期（持有 5-10 天调仓）
  - 市场状态：熊市强、牛市弱；**42d 窗口在抱团年(2021)反而有效(+19.3%)**，是 21d 反转失效环境的解法
  - 市值：全市场，大盘年(2017)略负
- **注意**：必须剔除股价<3 元（面值退市主力），否则幸存者偏差砍半收益
- **窗口微调**：30-42d 是高原，42d 稳健；30d 全正年份但抱团年保护弱

### 因子 2：量价背离 a101_16
- **定义**：`-rank(cov(rank(high), rank(vol), 20))`，价量负相关 = 缩量涨/放量跌
- **方向**：买价量背离的（缩量上涨健康）
- **适配环境**：横截面全市场，2020 结构性行情抗跌，换手高(33-38%)需扣成本
- **本质**：与"放量见顶"同源，换到横截面维度

### 因子 3：低波动 vol_21d
- **定义**：`std(日收益, 21天)`，买低波动
- **方向**：低波动异象（低风险高收益，A 股显著）
- **适配环境**：横截面，防御性强，适合震荡市

### 因子 4-6：价值 BP / SP / DP
- **定义**：`BP=1/pb`（账面市值比）、`SP=1/ps_ttm`（销售收益率）、`DP=dv_ttm`（股息率）
- **方向**：买低估值的（低 PB / 低 PS / 高股息）
- **适配环境**：
  - 周期：中长周期（季度调仓即可，换手 4-5% 极低）
  - 市场状态：**抱团年(2021)有效**，正好补反转的失效年份
  - 注意：低 PB 天然偏小盘，与市值因子部分重叠
- **价值**：换手极低（成本几乎为 0），是"降换手"的主力腿

### 因子 7：现金流质量（cfps_yoy / ocf_yoy / ocfps / ocf_to_debt）
- **定义**：每股现金流同比、经营现金流同比、每股经营现金流、经营现金流/负债
- **方向**：买"真金白银经营现金流强"的
- **适配环境**：季度频（PIT 对齐），中长周期
- **关键区分**：市场奖励"经营现金流"，**不奖励"账面盈利"（ROE/ROA/毛利率横截面无 alpha）**

### 因子 8：成长（dt_netprofit_yoy 扣非净利同比 / roe_yoy）
- **定义**：扣非净利润同比增速、ROE 同比增速
- **方向**：买增速高的
- **适配环境**：季度频，中长周期，2020 成长行情有效(+26%)

### 因子 9：放量见顶（择时）
- **定义**：日线量比 > 2 且当日上涨 → 未来看跌
- **方向**：单股票择时，出现此信号减仓/回避
- **适配环境**：不看市场状态（独立于牛熊），低频低换手
- **本质**：唯一有效的时间序列择时 alpha（其余振荡器时间序列全部证伪）

## 三、合成因子（已验证的最优组合）

| 组合 | 净年化 | 夏普 | 正年份 | 换手 |
|------|--------|------|--------|------|
| 反转42d + 量价背离 a101_16 | +22.34% | 1.53 | 11/11 | 32.7% |
| 反转42d + 量价背离 + 价值 + 现金流 + 成长（全合成） | +15.54% | 1.11 | 11/11 | 14.7% |

**合成规则**：各因子横截面 z-score 等权（滚动 IC 加权已证伪不如等权）。

- **低成本环境**：用"反转42d + 量价背离"（收益最高 +22.34%）
- **高成本/大资金环境**：用"全合成"（换手减半 14.7%，正年份 11/11 更稳）

## 五、使用规则（方法论）

1. **维度先于因子**：先确认信息源（价格/量/基本面），价格维度只有反转一条，别在价格维度重复挖
2. **环境标注**：每个因子必须标注"周期/市场状态/市值段"的适配环境，作为组合开关依据
3. **分层筛选**：先粗筛（小样本 IC）后精筛（回测+分年度+退市过滤），别一次全量精扫
4. **验证链条不可跳**：IC → 多空回测 → 扣成本 → 分年度 → 幸存者偏差 → 退市过滤 → 正交性
5. **幸存者偏差**：反转/价值"买跌"天然面对退市股坑，必须剔股价<3 元
6. **正交性**：新因子合成后必须提升夏普/正年份，否则是已有因子的变体
